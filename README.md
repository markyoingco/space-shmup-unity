# Space SHMUP

Unity 2D arcade shooter inspired by classic space shooter games.

## Features

- Player movement and shooting
- Enemy behavior
- Collision detection
- Score tracking
- Scene-based gameplay logic

## Tech Stack

- Unity
- C#
- 2D Physics
- Game Objects
- Prefabs

## Course Context

Built for COSC 3550 Programming Computer Games coursework at Marquette University.
