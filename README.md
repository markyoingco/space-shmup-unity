# Space SHMUP

Top-down space shooter with multiple enemy types, weapon upgrades, shields, power-ups, and wave-based combat across a scrolling starfield.

## Features

- Player movement and shooting
- Multiple enemy types
- Weapon upgrades and power-ups
- Shields and collision detection
- Wave-based combat and parallax starfield

## Tech

- Unity
- C#

## Open in Unity

1. Open Unity Hub.
2. Add this project folder.
3. Use Unity 2022.3 LTS (project version: 2022.3.62f3).

## Course Context

Built for COSC 3550 Programming Computer Games coursework at Marquette University.
